Pan Canvas

Middle Click + Drag
Alt + Left Click + Drag
Shift + Ctrl + Mouse Wheel (pan vertically)
Shift + Mouse wheel (pan horizontally)

Zoom Canvas

Ctrl + Mouse Wheel
Ctrl + Middle Click + Drag
Zoom in / out: Ctrl + Plus / Ctrl + Minus
Actual size (100%): 0

Tablet Mode

Turn it on with the button in the title bar or via View -> Tablet Mode
Pan Canvas: Right Click + Drag
Zoom Canvas: Ctrl + Right Click + Drag
Context menu: Right Click without dragging
Can be changed in Settings -> Settings -> Tablet Mode

Lock Images

Click the padlock in the corner of the window or use View -> Lock Images
Locked items can't be selected, moved or edited
You can still pan and zoom the canvas
While locked, Left Drag pans and Right Drag zooms
Can be changed in Settings -> Settings -> Lock Icon

Zoom in on Item

Double-click on item
Double-click again to get back to previous view

Select Items

Single Item: Left Click
Add to or remove from selection: Shift + Left Click
Rubberband Selection: Left Click + Drag
Add with rubberband (continuous select): Shift + Drag on empty canvas
Edit the selected note or drawing, or enter the group: Return
Clicking a locked item shows an "Unlock" button

Move Selected Items

Left Click + Drag
Shift while moving: only horizontally or vertically

Transform by Dragging on the Image

Rotate: Ctrl + Drag
Snap rotation: Ctrl + Shift + Drag, or Shift on the handles (45° by default; Settings > Images & Items)
Scale: Ctrl + Alt + Drag left or right
Scale from the center: Alt on the scale handles
Opacity: Ctrl + Alt + Shift + Drag left or right
Flip: Alt + Shift + Drag in the direction to flip
These controls can be changed in Settings > Keyboard & Mouse

Scale or Rotate Each Item Around Its Own Center

Shift + Alt while scaling or rotating several selected items

Arrange, Align, Normalize

These actions apply to the selected items, or to all items if nothing is selected
Align: Ctrl + Arrow Keys
Arrange by name, path, hierarchy order, time added or randomly: Ctrl + Alt + N, D, O, A or R (repeating reverses the order)
Normalize size (longest side), height, width and scale: Ctrl + Alt + Up, Left, Right and Down
Duplicate: Ctrl + D

Images (Images Menu)

Focus next or previous image: Right / Left
Slideshow of the selection: Alt + S (Esc to stop)
Open source (file or web page): Ctrl + Shift + O
Replace image: Images > Replace Image
Manage images (downscale, convert, discard cropping, embed or link): Ctrl + Shift + J
Relink missing images: Ctrl + Alt + Shift + R or double-click
Pasting the address of a web page imports all its images

Crop

Crop with handles: Ctrl + Alt + Shift + C; Shift keeps the aspect ratio and Shift + Alt makes a square
Crop the selection to a rectangle: hold C + Drag
Pan the image inside the crop: hold V + Drag
Zoom inside the crop: hold V + Shift + Drag
Reset cropping: Ctrl + Shift + C

Inspect

Zoom by dragging: hold Z + Drag
Show the color under the cursor: hold S + Drag
Show the pixel coordinates: hold D + Drag

Open a Scene

Double-click the empty canvas
Open the last scene: Ctrl + Shift + L

Move Window

Right Click + Drag (a click without dragging opens the menu)
While maximized, Right Click + Drag pans the canvas

Window Modes (View > Window)

Click-through (the mouse goes to the windows behind): Ctrl + Alt + T. Turn it off with the tray icon, or with the shortcut if global shortcuts are on (Settings > Window)
Opacity: Ctrl + Alt + Up / Ctrl + Alt + Down
Without title bar, drag the window border to resize the window

Grid and Snapping (View > Canvas)

Show grid: Ctrl + '
Snap to grid: Ctrl + Shift + '
Snap to the edges of other items: Shift + Space
Hold Alt while moving items to not snap

Groups (Group menu)

Group selected items: Ctrl + G
Ungroup: Ctrl + Shift + G. With items inside a group selected, they leave their group and go to the group that contains it
Double click a group to select items inside it
Double click the title of a group to rename it
Moving items onto a group puts them into it; moving them out of their group takes them out of it. Onto a closed group with subgroups, they go into the closed group
Subgroups: Double click a group and group items inside it
Add to Group: Select one group and the items to add
Remove from Group: The selected items go to the group's parent
Enter Group / Exit Group: Select the items inside the group, or the group of the selected items
Group Style: Background color, border color, width, line style and shape (straight, zigzag, wave, scallops, battlements), title color and size, opacity
Arrange Contents / Normalize Contents: Arrange, align, distribute, stack or normalize the items inside the selected group; subgroups count as one item
Focus Group: Fit the view to the group

Hierarchy (Items menu)

Make selected items children of the item selected first: P
Unparent: Shift + P
Lock selected items: Alt + L
Unlock all items: Alt + Shift + L
Edit comment: Alt + C
Rename: F2
Show hierarchy panel: Ctrl + J

Edit Text

Double Click on Text
Press Enter or click elsewhere to stop editing
Shift + Enter for a new paragraph or list item
A formatting toolbar is shown above the text while editing
Bold / Italic / Underline: Ctrl + B / Ctrl + I / Ctrl + U
Strikethrough: Ctrl + Shift + X
Align left / center / right: Ctrl + Shift + L / E / R
Numbered list / bullet list / checklist: Ctrl + Shift + 7 / 8 / 9
Click a check box to tick it
Indent list items: Tab / Shift + Tab, or Ctrl + ] / Ctrl + [
Insert link: Ctrl + K; Ctrl + Click on a link to open it (links to .mref files open in myRef)
Paste as plain text: Ctrl + Shift + V
Drag the right edge of the text to set a fixed width with word wrap

Drawing (Insert menu)

Start or stop drawing: Ctrl + Shift + D (with a drawing selected, continue drawing on it)
Double click a drawing to continue drawing on it
Tools: Pen D, Line L, Arrow A, Rectangle R, Ellipse C, Eraser E
Hold Shift for lines at 45 degree steps, squares and circles
The eraser removes whole strokes
Line width is in screen pixels at the current zoom
Esc or Enter to stop drawing

Text Notes (Text menu)

Formatting selected notes without editing them applies to the whole text of all selected notes (including notes in selected groups)
Copy format: Ctrl + Alt + C
Paste format: Ctrl + Alt + V
Clear formatting: Ctrl + \
Inserting text while an image is selected attaches the note to the image
