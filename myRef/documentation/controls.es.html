Desplazar el lienzo

Clic central + arrastrar
Alt + clic izquierdo + arrastrar
Mayús + Ctrl + rueda del ratón (desplazar en vertical)
Mayús + rueda del ratón (desplazar en horizontal)

Zoom del lienzo

Ctrl + rueda del ratón
Ctrl + clic central + arrastrar
Acercar / alejar: Ctrl + Más / Ctrl + Menos
Tamaño real (100%): 0

Modo tablet

Actívalo con el botón de la barra de título o en Ver -> Modo tablet
Desplazar el lienzo: clic derecho + arrastrar
Zoom del lienzo: Ctrl + clic derecho + arrastrar
Menú contextual: clic derecho sin arrastrar
Se puede cambiar en Configuración -> Configuración -> Modo tablet

Bloquear las imágenes

Haz clic en el candado de la esquina de la ventana o usa Ver -> Bloquear imágenes
Los elementos bloqueados no se pueden seleccionar, mover ni editar
El lienzo se puede seguir desplazando y haciendo zoom
Con el bloqueo, arrastrar con el botón izquierdo desplaza y con el derecho hace zoom
Se puede cambiar en Configuración -> Configuración -> Candado

Acercar un elemento

Doble clic en el elemento
Doble clic otra vez para volver a la vista anterior

Seleccionar elementos

Un elemento: clic izquierdo
Añadir o quitar de la selección: Mayús + clic izquierdo
Selección con recuadro: clic izquierdo + arrastrar
Añadir con recuadro (selección continua): Mayús + arrastrar en vacío
Editar la nota o el dibujo seleccionado, o entrar en el grupo: Intro
Un elemento bloqueado se desbloquea con el botón «Desbloquear» que aparece al pulsarlo

Mover los elementos seleccionados

Clic izquierdo + arrastrar
Mayús mientras mueves: solo en horizontal o en vertical

Transformar arrastrando sobre la imagen

Girar: Ctrl + arrastrar
Girar en pasos fijos: Ctrl + Mayús + arrastrar, o Mayús en las asas (45° por defecto; Ajustes > Imágenes y elementos)
Escalar: Ctrl + Alt + arrastrar a izquierda o derecha
Escalar desde el centro: Alt en las asas de escala
Opacidad: Ctrl + Alt + Mayús + arrastrar a izquierda o derecha
Voltear: Alt + Mayús + arrastrar en la dirección del volteo
Estos controles se cambian en Ajustes > Teclado y ratón

Escalar o girar cada elemento sobre su propio centro

Mayús + Alt mientras escalas o giras varios elementos seleccionados

Organizar, alinear, normalizar

Estas acciones se aplican a los elementos seleccionados, o a todos si no hay nada seleccionado
Alinear: Ctrl + flechas
Organizar por nombre, ruta, orden de jerarquía, inserción o al azar: Ctrl + Alt + N, D, O, A o R (repetir invierte el orden)
Normalizar tamaño (lado más largo), alto, ancho y escala: Ctrl + Alt + ↑, ←, → y ↓
Duplicar: Ctrl + D

Imágenes (menú Imágenes)

Enfocar la imagen siguiente o anterior: → / ←
Pase de diapositivas de la selección: Alt + S (Esc para terminar)
Abrir el origen (archivo o web): Ctrl + Mayús + O
Reemplazar la imagen: Imágenes > Reemplazar imagen
Gestionar imágenes (reducir, convertir, descartar recorte, incrustar o enlazar): Ctrl + Mayús + J
Reenlazar imágenes perdidas: Ctrl + Alt + Mayús + R o doble clic
Pegar la dirección de una página web importa todas sus imágenes

Recortar

Recortar con asas: Ctrl + Alt + Mayús + C; Mayús mantiene la proporción y Mayús + Alt hace un cuadrado
Recortar la selección a un recuadro: mantener C + arrastrar
Desplazar la imagen dentro del recorte: mantener V + arrastrar
Zoom dentro del recorte: mantener V + Mayús + arrastrar
Restablecer el recorte: Ctrl + Mayús + C

Inspeccionar

Zoom arrastrando: mantener Z + arrastrar
Ver el color bajo el cursor: mantener S + arrastrar
Ver las coordenadas del píxel: mantener D + arrastrar

Abrir una escena

Doble clic en el lienzo vacío
Abrir la última escena: Ctrl + Mayús + L

Mover la ventana

Clic derecho + arrastrar (un clic sin arrastrar abre el menú)
Con la ventana maximizada, clic derecho + arrastrar desplaza el lienzo

Modos de ventana (Ver > Ventana)

Transparente al ratón (los clics van a las ventanas de detrás): Ctrl + Alt + T. Se desactiva con el icono de la bandeja, o con el atajo si los atajos globales están activados (Ajustes > Ventana)
Opacidad: Ctrl + Alt + arriba / Ctrl + Alt + abajo
Sin barra de título, arrastra el borde de la ventana para cambiar su tamaño

Cuadrícula e imantado (Ver > Lienzo)

Mostrar cuadrícula: Ctrl + '
Imantar a la cuadrícula: Ctrl + Mayús + '
Imantar a los bordes de otros elementos: Mayús + Espacio
Mantén Alt al mover elementos para no imantar

Grupos (menú Grupo)

Agrupar los elementos seleccionados: Ctrl + G
Desagrupar: Ctrl + Mayús + G
Doble clic en un grupo para seleccionar elementos dentro de él
Doble clic en el título de un grupo para renombrarlo
Al mover elementos sobre un grupo entran en él; al sacarlos de su grupo, salen de él. Sobre un grupo cerrado con subgrupos, entran en el grupo cerrado
Subgrupos: doble clic en un grupo y agrupar elementos dentro de él
Incluir en el grupo: selecciona un grupo y los elementos que quieras añadir
Quitar del grupo: los elementos seleccionados pasan al padre del grupo
Entrar en el grupo / Salir del grupo: selecciona los elementos del grupo, o el grupo de los elementos seleccionados
Estilo del grupo: color de fondo, color, grosor, trazo y forma del borde (recta, zigzag, onda, festón, almenas), color y tamaño del título, opacidad
Organizar contenido / Normalizar contenido: organizar, alinear, distribuir, apilar o normalizar los elementos del grupo seleccionado; los subgrupos cuentan como un solo elemento
Enfocar grupo: encuadra el grupo en la vista

Jerarquía (menú Elementos)

Hacer los elementos seleccionados hijos del primero seleccionado: P
Desemparentar: Mayús + P
Bloquear los elementos seleccionados: Alt + L
Desbloquear todos los elementos: Alt + Mayús + L
Editar comentario: Alt + C
Renombrar: F2
Mostrar el panel de jerarquía: Ctrl + J

Editar texto

Doble clic en el texto
Pulsa Intro o haz clic en otro sitio para terminar de editar
Mayús + Intro para un párrafo o un elemento de lista nuevo
Mientras editas aparece una barra de formato encima del texto
Negrita / cursiva / subrayado: Ctrl + B / Ctrl + I / Ctrl + U
Tachado: Ctrl + Mayús + X
Alinear a la izquierda / centrar / a la derecha: Ctrl + Mayús + L / E / R
Lista numerada / con viñetas / de verificación: Ctrl + Mayús + 7 / 8 / 9
Haz clic en una casilla para marcarla
Sangría de elementos de lista: Tab / Mayús + Tab, o Ctrl + ] / Ctrl + [
Insertar enlace: Ctrl + K; Ctrl + clic en un enlace para abrirlo (los enlaces a archivos bee se abren en myRef)
Pegar como texto sin formato: Ctrl + Mayús + V
Arrastra el borde derecho del texto para fijar el ancho con ajuste de línea

Dibujo (menú Insertar)

Empezar o terminar de dibujar: Ctrl + Mayús + D (con un dibujo seleccionado, sigues dibujando en él)
Doble clic en un dibujo para seguir dibujando en él
Herramientas: lápiz D, línea L, flecha A, rectángulo R, elipse C, borrador E
Mantén Mayús para líneas en pasos de 45 grados, cuadrados y círculos
El borrador elimina trazos completos
El grosor de línea está en píxeles de pantalla con el zoom actual
Esc o Intro para terminar de dibujar

Notas de texto (menú Texto)

Si das formato a notas seleccionadas sin editarlas, se aplica a todo el texto de todas ellas (también a las notas de los grupos seleccionados)
Copiar formato: Ctrl + Alt + C
Pegar formato: Ctrl + Alt + V
Limpiar formato: Ctrl + \
Si insertas un texto con una imagen seleccionada, la nota queda unida a la imagen
