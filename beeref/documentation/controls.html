Pan Canvas

Middle Click + Drag
Alt + Left Click + Drag
Shift + Ctrl + Mouse Wheel (pan vertically)
Shift + Mouse wheel (pan horizontally)

Zoom Canvas

Ctrl + Mouse Wheel
Ctrl + Middle Click + Drag
Zoom in / out: Ctrl + Plus / Ctrl + Minus
Actual size (100%): 0

Tablet Mode

Turn it on with the button in the title bar or via View -> Tablet Mode
Pan Canvas: Right Click + Drag
Zoom Canvas: Ctrl + Right Click + Drag
Context menu: Right Click without dragging
Can be changed in Settings -> Settings -> Tablet Mode

Lock Images

Click the padlock in the corner of the window or use View -> Lock Images
Locked items can't be selected, moved or edited
You can still pan and zoom the canvas
While locked, Left Drag pans and Right Drag zooms
Can be changed in Settings -> Settings -> Lock Icon

Zoom in on Item

Double-click on item
Double-click again to get back to previous view

Select Items

Single Item: Left Click
Multiple Items: Ctrl + Left Click
Rubberband Selection: Left Click + Drag

Move Selected Items

Left Click + Drag
Shift while moving: only horizontally or vertically

Snap Rotation

Shift or Ctrl while rotating

Scale or Rotate Each Item Around Its Own Center

Shift + Alt while scaling or rotating several selected items

Arrange, Align, Normalize

These actions apply to the selected items, or to all items if nothing is selected
Align: Ctrl + Arrow Keys
Duplicate: Ctrl + D

Open a Scene

Double-click the empty canvas
Open the last scene: Ctrl + Shift + L

Move Window

Ctrl + Alt + Left Click + Drag

Window Modes (View > Window)

Click-through (the mouse goes to the windows behind): Ctrl + Alt + T. Turn it off with the tray icon, or with the shortcut if global shortcuts are on (Settings > Window)
Opacity: Ctrl + Alt + Up / Ctrl + Alt + Down
Without title bar, drag the window border to resize the window

Grid and Snapping (View > Canvas)

Show grid: Ctrl + '
Snap to grid: Ctrl + Shift + '
Snap to the edges of other items: Shift + Space
Hold Alt while moving items to not snap

Edit Text

Double Click on Text
Press Enter or click elsewhere to stop editing
Shift + Enter for newline
